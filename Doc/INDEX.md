## 两处需要留意

1. **两份 README 主题不同，不合并**：`Doc/README.md` 是**背景侧**（为什么做这个设备），
   根 `Readme.md` 是**技术侧**（怎么做的）。属于「有意并存」——但读者容易只找到一份，
   所以两行都登记，并各自标明主次。
2. **仿真 ≠ 实测**：`Readme_PID.md` 的调参结论来自 Simulink，不能当实车实测引用。
   引用时必须说明是仿真结论。

> **注**：两仓的 `AGENTS.md` 内容相同（Jaccard 1.000），审计会报「强冗余簇」。
> 这是**有意的**——治理规则应当统一，规则文件不参与文档去重。
> 审计工具默认已把 `AGENTS.md` / `CLAUDE.md` 排除在文档审计之外。
